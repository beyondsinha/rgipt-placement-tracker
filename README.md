# RGIPT Placement Tracker

A student-built placement tracking and analytics dashboard for **Rajiv Gandhi Institute of Petroleum Technology (RGIPT)**.

The tracker provides a centralized interface to explore placement opportunities, compare CTC and stipend information, check eligibility, and view placement insights.

> **Note:** This is an independent, student-created project and is not an official RGIPT placement portal or institutional publication.

---

## Features

* 📊 **Placement Dashboard**

  * Total offers and companies
  * Average, median and highest CTC
  * Stipend statistics
  * Placement overview

* 📋 **Placement Database**

  * Searchable placement records
  * Filter by company, sector, branch and offer type
  * CTC and stipend information
  * Role, location and eligibility details
  * Selection status

* 🎓 **Eligibility Finder**

  * Enter branch and CGPA
  * Find matching placement opportunities
  * View eligibility requirements for each company/role

* 📈 **Placement Insights**

  * Companies by sector
  * Branch-wise offer distribution
  * CTC statistics
  * Placement trends and summaries

* 🔄 **Google Sheets Integration**

  * Placement records can be maintained through Google Sheets
  * The website fetches the latest available placement data automatically

* ⚙️ **Admin Workspace**

  * Data management and import/export utilities
  * Placement data maintenance

* 📱 **Responsive UI**

  * Optimized for desktop and mobile screens
  * Dark-themed interface

## Deployment

The application is designed to be deployed on **Vercel**.

### Deploy using GitHub

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Select **Next.js** if not automatically detected.
4. Configure any required environment variables.
5. Deploy.

Every push to the connected GitHub branch will trigger a new Vercel deployment.
